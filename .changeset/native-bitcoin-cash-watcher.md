Add native Bitcoin Cash observation scanning through BCHN RPC with explicit chain selection, bounded configuration, canonical treasury validation, scanner scheduling, and sync health checks. Requires coordinated scanner, observation extractor, and address codec releases exposing the native Bitcoin Cash APIs.

Require Node.js 22.18 or later and npm 11.6.2 for the Bitcoin Cash dependency graph. Align the development, CI and Docker runtime profiles with this minimum version.
